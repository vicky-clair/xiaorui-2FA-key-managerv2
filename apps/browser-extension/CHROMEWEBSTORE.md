## 📝 详细功能介绍 (Store Listing Description)

### 简体中文：
> **Secure Authenticator** 是一款纯本地、零知识端到端加密的双重认证（2FA / TOTP）管理插件。
>
> **✨ 核心特性**：
> 1. **智能 2FA 二维码扫描与识别**：当网页中出现 2FA 绑定二维码时，插件自动识别并弹出优雅的导入提示，无需手动输入繁琐的长串密钥代码。
> 2. **严格 2FA 白名单过滤**：严格仅对 `otpauth://` 协议的 2FA 密钥响应，绝不拦截或弹出普通网页二维码或支付码，无感且不打扰。
> 3. **自定备注与文件名**：导入时支持用户自定义修改账号备注和平台名称，核对无误后一键完成加密保存。
> 4. **纯本地 AES-256-GCM 强加密**：所有动态口令密钥均在本地加密，主密码绝不上传云端，保障 100% 隐私安全。
> 5. **动态倒计时与一键复制**：支持 30 秒倒计时进度条实时变色展示，点击任意卡片即可一键复制动态口令。

## 🛡️ 权限申报与合理性证明 (Permissions Justification)

| 权限名称 | 使用场景与审核理由 |
| :--- | :--- |
| **`storage`** | 用于在浏览器本地安全沙箱存储用户经 AES-256-GCM 高度加密的 2FA 密文库与偏好设置。 |
| **`activeTab`** | 用于用户点击导入时，在当前活跃标签页弹出确认与备注修改模态窗口。 |
| **`scripting`** | 用于在包含 2FA 绑定二维码的页面中执行条码扫描与悬浮提示。 |
| **`host_permissions: <all_urls>`** | 用于在用户浏览任何支持 2FA 绑定的网站（如 GitHub, Google, 币安, AWS 等）时扫描页面二维码以实现一键快捷导入。 |
